# Public evidence edition

This repository is derived from the complete private handover dated 15 November 2026. The private version retains all 59 original screenshot files and uploaded transcripts. This edition retains 32 selected gallery PNGs, selected proof crops, the newer website capture, curated service records and current documentation.

Private evidence archives, local source backups, historical installer scripts, actual tfvars/backend files, state, saved plans and provider binaries are omitted. The original source `.tf`, `server/`, `website/` and `monitor/` assets and dependency lockfile are unchanged.

Event records were parsed and access-key identifier fields replaced with `REDACTED_FOR_PUBLIC_REPOSITORY`. These fields are not needed to assess the timing, target instance, event ID or Scheduler caller role. Some filenames retain `original` because they originated as lookup responses, but this public edition is a redacted derivative. Keep the unmodified record in the private handover when comparing evidence.

The verification JSON is extracted from the uploaded terminal session, not fetched anew during packaging. The source transcript remains in the private handover. Resource and account identifiers are retained to keep the claim-to-evidence chain intelligible. Curate any future screenshots before adding them.
